# 错误报告 2026-06-19

## 错误类型
数据缺失：user message 中未找到 `<DATA>...</DATA>` 标签

## 错误原因
本次任务触发时，user message 不包含行情数据（无 `<DATA>` 与 `</DATA>` 标签对）。
无法提取或解析 JSON 行情数据，按规则禁止编造数据，终止报告生成。

## User Message 前 500 字符

```
你是 A 股每日行情简报的分析者。本次任务由本地派发器通过 API trigger 触发。
数据所在位置（关键）
当前 user message 中包含一段被 <DATA>...</DATA> 标签包裹的 JSON 字符串——那是行情数据。
你的第一步永远是：

在 user message 中找到 <DATA> 和 </DATA> 之间的内容
用 JSON 解析器（json.loads）解析它

⚠️ 严禁的行为：

严禁 使用 SKILL.md 中的占位符示例数据。那是格式说明文档，不是可用数据
严禁 在找不到 DATA 标签时编造数据生成报告。无数据就走错误流程

执行步骤（详细约束见仓库根目录 SKILL.md）
1. 提取并解析
```

## 建议后续处理
请检查本地派发器，确认触发 API 时已将行情 JSON 数据正确包裹在 `<DATA>...</DATA>` 标签内随 user message 一并传入。
